# Dataset Instructions

The dataset used for this assessment is the U.S. Bureau of Transportation Statistics airline on-time performance dataset.

Dataset source:  
https://www.transtats.bts.gov/

The local CSV file used by the notebook is:

`T_ONTIME_REPORTING.csv`

The file is larger than 100 MB and is therefore not committed to this GitHub repository.

To reproduce the analysis:

1. Download the required airline on-time performance CSV from the Bureau of Transportation Statistics source.
2. Save the file as `T_ONTIME_REPORTING.csv`.
3. Place the file in the parent lab directory:

   `C:\ITO5202\labs\`

4. Start the PySpark Docker container.
5. Open the assessment notebook from the `ITO5202-Big-Data` folder.
6. Run the notebook from top to bottom.
